# Site design system

Baseline: published `ec2983e`; branch `feat/site-design-system`. Request: improve all pages, elements and feature presentation with coordinated colors and themes. This work preserves calculation rules, dataset meanings, exports, private records and page URLs.

The product is a scholarly observatory and collection of calculation tools. Its principal artifacts are charts, calendar comparisons, source records and symbolic diagrams. Keep the engraved circles, serif headings and factual/source qualifications. Strengthen hierarchy and controls rather than adding decorative dashboards.

## Delivery

- Three named themes: Parchment, Midnight and Mineral. Explicit palette tokens, never a blanket inversion filter. Appearance uses one isolated preference key and no domain events.
- Global component rules for controls, forms, result panels, tables, selected states, disclosures, focus and mobile layouts.
- Eight page families with stable accent colors and visible names already present in headings/navigation. Family colors identify subject areas; they never classify an astrological outcome.
- Early validated preference bootstrap and deterministic style order on every HTML document. The coverage manifest lists all 133 application routes and the AI reference document.
- Homepage research links remain available in an expandable group so the date/place form appears sooner.

## Ownership and review
