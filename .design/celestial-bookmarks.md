# Celestial timeline bookmarks

Baseline: published `55a6ce0c0fae2f29b8ddc80842597c239ad3e70d`. Request: equinox/solstice bookmarks, lunar icons on calendar sliders, and an artistic colored treatment of timelines and bookmarks.

The primary job is to locate a meaningful instant, compare its calendar labels, inspect its calculation context, and explicitly save a public study bookmark. Extend the existing black/neon instruments and shared date navigator. Preserve the native range input, readable adjacent detail, source qualifications and private-input boundaries.

## Contract

- Show March/September equinoxes and June/December solstices with distinct icons, labels and colors. Names do not assume a hemisphere. Use the existing canonical astronomical searches; no hardcoded annual dates.
- Keep the four annual season guides discoverable beyond a short current date window. Display exact event UTC and the observer's local date/zone. Shared astronomical markers do not constitute independent calendar predictions.
- Add calculated lunar-phase icons to actual study-day/calendar lanes. Use held astronomy or bounded cached canonical phase calculations. Missing, ambiguous and source-only dates remain explicitly unavailable; do not invent lunar values for source-year claims or imply crescent visibility.
- Keep exact event markers separate from indexed daily samples. Hover/focus only previews. A deliberate action may cast the exact UTC where supported, or select an honestly labeled nearest study day while retaining the requested clock. Never silently snap an out-of-range event to a range endpoint.
- Automatic guides do not write saved bookmarks. Explicit saves use the existing bounded public bookmark key/schema; preserve failure recovery, cap, removal, reload and cross-navigator behavior.
- Retain dense-range bounds, stable identities, paged readable lists, keyboard/tap targets, Escape/focus return, disabled/stale guards and 320px/zoom reflow. Color has redundant text and shape cues.
- Keep every existing route, calculated chart, canonical JSON/CSV and CI gate. Theme and hover changes do not run ephemerides or read private records.

## Review

Six AI engineering perspectives cover integration, data adapters, shared interactions, styling, verification and independent review. The first review captured sixteen exact-baseline images and identified uniform ticks, repeated generic date cards, missing lunar-phase shape, exact-time ambiguity and bookmark privacy as the main priorities. The second review inspects the implementation; the third binds actual screenshots, event/phase data, bookmark interactions and release evidence to the held source. These are engineering reviews, not human usability research.
