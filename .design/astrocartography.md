# Astrocartography atlas

Design Partner create/surface workflow; 4 November 2026. Read foundations, accessibility, verification, existing site design and desktop workbench notes. No existing `.design/*-report.md` was present for this feature.

The main job is geographic exploration with an explicitly supplied moment: see where each planet is angular, inspect a place, compare the same declared editorial rule across places, and distinguish those calculations from source-based interpretations. The geographic map is the dominant artifact. This is an original black instrument desk, not a copy of paid desktop artwork. Coastline geometry and original calculations supply the visual structure; no remote tile service, decorative country scores or invented outcome probability.

Desktop uses a compact profile at left, the large world map in the centre, and destination inspection at right. Medium widths move inspection below the map in two columns. Narrow screens use a collapsible moment form above the map, then a full-width inspector. Native controls and local table scrolling retain the comparison workflow. Planet colors identify bodies; solid/dashed/dotted angle strokes and literal body/angle names provide redundant encoding. The grey graticule is explicitly geographic, not an astrological grid.

The initial public equinox is 2024-03-20 03:06 UTC at Greenwich; personal profiles are never recalled. A missing clock cannot produce angular lines. Source coordinates do not alter the global line geometry when UTC remains fixed. Map/city inspection retains the UTC instant; an exact city catalogue zone is available, while manual/map points visibly declare UTC as a study assumption until edited. No longitude-to-time-zone inference.

Map display uses equirectangular projection only. All angular coordinates, distances, crossings, ranking contributions, relocated charts and nine-framework readings come from the canonical engine. Pointer selection must invert SVG `getScreenCTM`, including inherited CSS scaling. Zoom/pan has buttons and keyboard equivalents; map selection also has an explicit coordinate form and named city/line controls. Wheel scrolling is not trapped. No interactive SVG is hidden inside role=image semantics.

Profile edits invalidate held calculations and exports. Displayed calculation filters/purpose/radius can recompute only against an already valid held profile. Manual destination edits invalidate its inspection and export until explicitly inspected. Kept places use bounded session memory (12), not automatic browser persistence; map crossings are kept as coordinates, never inherited claims about a later moment. JSON/CSV exports are deliberate. Model context has an exact input-only preview and separate opt-in; source/canonical values are recomputed on the companion. Only allowlisted navigation actions may apply from chat.

Thematic fit is an explicitly editorial proximity/weight metric, not probability, safety or a practical relocation recommendation. The page exposes weights, component contributions, sources and limitations. Polar/unavailable relocated geometry remains absent with reasons. Independent calendar labels do not turn a shared sky into independent corroborating evidence.
