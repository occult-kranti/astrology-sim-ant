# Birth chart console and static offline library

The primary job is to inspect and compare one calculated birth chart. Keep the
recorded instant, three declared frames, canonical data, source qualifications,
timing sensitivity, private import/export, clear action and every existing route.
No birth defaults or personal profiles belong in the repository or offline pack.

The requested Star Trek inspiration is interpreted as an original LCARS-like
console: segmented black panels, amber/coral/cyan structural bands, labeled
readouts and closely grouped operational controls. No franchise assets, audio,
logos or copied commercial templates. Color expresses interface roles and named
geometry, never guaranteed fortune, danger or predictive confidence.

Use a chart-first layout with detail controls and a numerical companion. Offer
the same held frames through the native selector, independently switchable chart
layers, inspectable planet and house details, angular relationships with explicit
orb conventions, bounded zoom/orientation, reset and portable image exports.
Every pointer action needs a keyboard alternative. Honor existing themes,
reduced motion, 320px reflow, 200% zoom, print and legible source links.

The frontend remains plain HTML/CSS/ES modules, with local computation in a module
worker. The explicit offline library downloads a hash-verified static inventory.
Incomplete downloads cannot claim readiness. Within the same worker edition, preserve a complete pack until
a replacement succeeds; accepting a new worker edition requires a fresh pack. Never cache birth query strings, private results, API
responses or external links. A portable ZIP offers the same static files for a
local server; a private HTML export is the no-server reading alternative.

Definition of done: actual controls and exports exercised, true offline reload,
unvisited-page navigation and calculation verified, interrupted download recovery,
scope-safe removal, no private cache entries, narrow/wide visual review and all
required inherited release gates. Publish and verify the exact live commit.
