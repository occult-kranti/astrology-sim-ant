# Live Symbol Studio surface brief

Mode: Operate. Goal: choose a shared instant/place/method, inspect a real chart or symbolic calculation, freeze it and export reproducible evidence. The studio is additive to pages/workbench.html and all dedicated tools.

Primary workflow: choose task → enter UTC/location or start live → inspect figure and values → pause/save/export. Optional planetary-hour following is opt-in and clearly reported; it only selects the square's planet when a valid hour exists. Letter-value outputs name input alphabet and ignored/rejected characters.

Scope: Western and Vedic chart renderers, seven Agrippa squares with Latin/Hebrew traces, nine navagraha squares, Hebrew gematria and IAST Kaṭapayādi. Reuse shared calculation context, live clock, symbol renderer and exports. A settings/setup section explains MCP capability metadata without claiming an unverified hosted endpoint or connecting automatically.

Invariants: preserve Workbench hidden IDs, saved input formats and deep anchors; add task/tradition filters without removing tool links. Use existing DS2 tokens, normal mobile scrolling and no generated diagrams. Source-derived findings are not browser proof.
