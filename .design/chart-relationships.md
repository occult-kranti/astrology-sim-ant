# Relationship chart design contract

The circle is the primary instrument. Relationships have distinct named geometry colors, line patterns and endpoint emphasis; traditional favorable/caution classifications remain separate source-attributed statements. An inline inspector keeps the selected pair and its governing convention near the chart. Hover/focus changes only presentation; explicit activation pins a relation.

Calendar ring colors derive from stable method IDs and stay consistent after filtering. Matched, changed and unavailable calendar outputs retain the declared UTC/wall-clock comparison. Unsupported calendar calculations remain unavailable. Selected and actually drawn rings are separately disclosed when the existing eight-ring cap applies.

Use the current parchment/ink/copper palette and semantic contrast-tested accents. Preserve the original Sun–Moon and heliocentric modes, all source readings, date navigation/bookmarks, exports and worker state. Recompose controls at narrow widths and provide normal list buttons as alternatives to thin SVG targets.

Baseline rendered evidence: the exact published `bf27046` atlas screenshots at 390 and 1440 pixels were directly inspected from the previous live-run archive. Current connectors have one thin copper style; related endpoints lack coordinated emphasis. A source-confirmed ring color mismatch occurs because controls use the original ring index while the SVG recolors a filtered list. These findings justify the changes.
