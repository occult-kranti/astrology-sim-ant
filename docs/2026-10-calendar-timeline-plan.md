# Synchronized chart and calendar timeline

Baseline: published `ae94fb003f00f3456635121e81f6616a6d6118a3`. Branch: `feat/peaceful-calendar-timeline`. The country study, complete2031 horizon and all prior routes remain available.

## Product goal and boundary

A single civil-date slider should update the supported sky charts, calendar labels and traditional-rule evidence for one explicit observer, zone and clock. Default window:30October2026–1January2031. Custom windows lie within1900–2100, with at most3660inclusive civil dates. This is a selected catalogue of implemented methods, not every chart or religious tradition.

Calculated celestial events can be forecast from an astronomical model. Documented treaty/cooperation milestones are past source records. Traditional classifications and modern editorial study indices do not establish a forecast of wars, peace agreements or successful actions. This work does not recommend military timing, rank countries, or infer national births. Peaceful study cards cover beginning, completion and learning through named existing profiles; dialogue and ceremony retain an unavailable dedicated-rule status where no supported method exists.

## Reader flow

1. Open the new chart timeline directly or from the existing country page, home or navigation. Set a range, local clock, public observer coordinates, IANA zone, house convention and fold policy.
2. Scrub one daily slider or use date/day/month/year controls. The selected rich frame is calculated lazily in a worker; no full collection of charts is precomputed on every drag. Cancel or edit to invalidate pending results and exports. Gaps, folds and unsupported UTC boundaries remain visible.
3. Compare ten Western sky bodies, twelve house cusps, a compact nine-graha sidereal view, selected calendar families and their implemented/unavailable variants. Optional catalogue-star coordinates retain their own frame and precision. No natal daśā, remedy or private stored profile is inferred.
4. Inspect named rule contributions, missingness, source locators and explicit editorial purpose mappings. Use the existing complete-date scan for its supported future window. A single selected sample is not a verdict on a whole day.
5. Jump to a source-qualified past milestone. The marker's civil date remains separate from the chosen observer and assumed clock. Signature, approval, legal entry into force and later registration are distinct. No historical correlation or predictive validation is inferred.
6. Download the complete selected frame as JSON/CSV, including selection, precision, sources and unavailable states. Calculation results are recomputed through canonical engines, not accepted from imported caller-supplied rows.

## Team and review process

Six specialist AI agents work with the root integrator: canonical engine, interface/worker, source records, study methods/MCP, independent QA, and independent source/calculation/performance review. These are AI-agent roles, not human professional endorsement or participant research. Three rounds comprise implementation, cross-review/corrections, and a held candidate with actual semantic/browser/export evidence.

File ownership is disjoint. Root owns navigation, registry, generated catalogue integration, CI, repository-level documentation and release. Existing core numerical engines and ranking weights are preserved. Shared catalogue changes require regenerating the horizon binding and checking the existing data parts for actual changes.

## Completion evidence

Meaningful focused and independent tests cover range limits, leap dates, skipped/gap/fold clocks, strict input contracts, common-instant chart consistency, source precision and worker replacement/cancellation. Actual browser tests cover slider keyboard use, narrow/wide layout, stale exports, errors/recovery and actual downloaded bytes. Source/driver hashes bind the held candidate. Run all five required repository gates, actual MCP transports, exact-head CI and production stress/verification/deployment. Verify live release identity and routes after publication. No hosted MCP, provider inference or model training is established by source support alone.
