# Studio expansion: five-member, four-round review

This panel consists of five independent AI-agent perspectives. It is not observed human usability research, a claim that all cited books were read in full, or approval by a cultural/religious authority. Root moderates and integrates; the five members review bounded source and product surfaces.

| Member | Perspective | Independent review responsibility |
|---|---|---|
| `ai_mcp` | Generative design, deterministic artwork and AI disclosure | Symbol algorithms, reproducible recipes, optional prompt transfer and source-qualified visual examples |
| `calendar_engine` | Arithmetic and explainable daily/hourly rules | Actual instant/day/hour boundaries, rule evidence, applicability and unavailable states |
| `calendar_research` | Books, cultural methods and standards | Bibliographic/passage/rights status, implementation claims, learning profiles and technical examples |
| `compare_ui` | International events and event UX | Official date provenance, rolling interval, coverage unknowns, date-only exports and selected-observer study samples |
| `qa_panel` | Independent mobile, accessibility and integration | Real browser workflows, stale state, numeric/artifact exports, privacy, source limitations and regressions |

Each round below records the actual artifact reviewed. Earlier calendar-observatory reviews belong to the previous release and do not count toward these four rounds.

## Round 3: corrected-candidate challenge

The same five members reviewed the materially revised candidate. Source and design reviewers verified edition/section retention and the explicit AI/procedural distinction. The arithmetic reviewer independently executed 20 calendar/ICS assertions on the actual event dataset and corrected standards helper; [receipt](evidence/studio-expansion/round3-calendar-independent.json). The events member checked dirty context, sampled-noon scope and output assumptions. QA ran the actual source, SVG/PNG/JSON and mobile workflows against corrected contracts.

Further changes from this round:

- Root found that old comparison/week export formats omitted the new on-screen guidance. JSON now includes `studyGuidance`, Markdown includes the source-labelled historical guidance section, and each available weekly row exports its sampled rules. Existing minimal AI packets and pure comparison/MCP schemas remain unchanged.
- The optional image adapter now rejects `application/jsonx` and sets `redirect: 'error'` for its fixed provider endpoint. Six fake-transport groups test its contract; these do not establish a paid or authenticated inference call.
- Delayed PNG callbacks, same-week stale-link recovery and source metadata were rechecked in real Chromium. The source/standards owner executed all16 demonstrations and seven actual download types; the downloaded SQLite example was executed with SQLite.

Intermediate receipts remain in `evidence/studio-expansion/round3-*`. A failing draft driver receipt is historical evidence of that run, not a passing release receipt.

A real final-round defect was fixed and rechecked: live minute updates could recreate nested hourly disclosures. Unchanged weekly snapshots now avoid unnecessary rerenders; the guidance mount restores the open hour and nested rule state only for the same observer/day/method cache key. Changed observers do not inherit that state.

A proposed source-link defect was disproved: the guidance module owns a trailing-slash URL object rather than importing the shared slash-trimmed string. Actual Pages-prefix links returned200. The finding was retracted and no unnecessary URL patch was made.
