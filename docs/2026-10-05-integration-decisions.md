The previous broad astronomy/calendar product matrix remains in `2026-10-research.md`. This follow-up concerns the actual Workbench's live graphics, common calculation context and external tools.

## Bounded review passes

1. Architecture: baseline tree matched remote; panel found duplicate/misaligned input state, daylight boundary errors, silently discarded symbol letters, eager assistant graph and origin-wide cache cleanup. Additive implementation selected.
2. Working-feature skepticism: independent suites challenge scan limits, input/schema drift, saved-state corruption, cancellation, explicit dates, reference arithmetic and symbolic provenance. See test/release evidence for material repairs.
3. Release: full browser page sweep, focused calculator/Studio journeys, real official-SDK protocol exchange, Pages project-path assets and exact release-SHA verification. Remote hosting/actual client setup and physical-device checks remain separate from these gates.
