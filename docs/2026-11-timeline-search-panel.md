## Acceptance contract

- Scan every declared civil-date sample in an explicitly bounded window, using the applied clock, observer, zone and ambiguity policy. Missing clocks remain unavailable; a daily scan does not establish whole-day absence of a short alignment.
- Reuse the supported canonical calendar and traditional-rule calculations. Scope is named implemented methods, not every religious tradition or every possible variant.
- Inspect all forty supported planetary angular branches at the chosen place. Distinguish a fixed explicit reference map from a changing event/transit map. The fixed map does not move merely because the timeline date changes.
- Keep all sampled rows, missingness and denominators. View filters and a displayed top list must not redefine a statistical test family or secretly discard nonmatches.
- Separate finite-grid exceedance frequencies, descriptive correlations, artificial relative-phase sensitivity and empirical outcome predictions. No outcome-labelled validation data are supplied; no probability of an attack, disaster, life event or successful relocation is estimated.
- State dependence, constant series, irregular UTC spacing, null assumptions, multiple testing, resolution and post-selection limits. Never increase resampling in response to a disappointing result.
- Improve the shared timeline and bookmark experience while retaining existing routes, sliders, saved public references and explicit actions. Private scan context stays in session memory unless deliberately exported.
- Support cancellation, stale-result protection, bounded MCP summaries, reproducible source records, offline distribution and independent tests. Pages remains deferred under the existing user instruction.

Six independent AI-agent perspectives cover canonical scanning, statistical methods, independent numerical challenges, interface implementation, browser QA and protocol integration. These are engineering/source reviews, not human practitioner certification or participant research.

## Loop 3: skeptical study, final corrections and acceptance

A saved request preceded an actual 1,096-day scan (2026-11-06–2029-11-05, Greenwich noon UTC). All 14,248 calendar rows and 43,840 map distances were retained. Optimized and brute results are semantically identical. Six dates match the arbitrary example lunar/calendar/weekday conditions. They are not validated good or bad days.

The map threshold passes **all 1,096 available samples**: Sun–MC alone stays within 0.376–284.653 km at this observer/clock, inside the declared 300 km radius. The statistics reviewer identified this nondiscrimination. The final UI now shows map pass/available/excluded counts and a clear notice when the map condition did not narrow the search. It does not add that condition as independent corroboration.

The only Holm-adjusted relative-phase fraction below .05 compares near-line count with closest-line distance (Spearman −0.267302; raw 1/1,024; adjusted 10/1,024). Both measure the same angular geometry. All other adjusted fractions are at least .474609. These findings concern an artificial relative-phase reference; no outcome labels, empirical forecast probabilities or causal inference are supplied. No filter or resampling budget was tuned after seeing the results.

An actual 3,660-day maximum run retained 47,580 calendar rows and 146,400 distances, produced 60,299,447 JSON bytes and matched a direct calculation of the final date. One Node run took about 20.8 seconds; process RSS after serialization was about 1.52 GB. This is a bounded operational measurement, not a claim of lower peak memory or successful operation on every phone. The complete-ledger size limit and short-range guidance remain.

Final new browser acceptance passed **420 checks**, with **36 real downloads and 31 directly reviewed screenshots**, zero runtime errors and no public-source/driver drift. Retention rehashed 596 public files plus the driver and all retained screenshots/downloads. Inherited timeline **2,067**, celestial bookmarks **231**, Astrocartography **126**, and standalone file-origin **53** checks passed. The map test made no external requests; standalone bindings match 53 build inputs and the current corpus. No physical-device or screen-reader certification is claimed.

The full engine passed **755** checks; the whole-site sweep covered **138 pages / zero errors**, with two inherited descriptor warnings. The full sweep precedes the final narrow map-threshold diagnostic; the final focused run covers that change. The static audit reported zero problems, and all twelve generator freshness commands passed. RAG retrieval passed **40,791** checks, and current local PostgreSQL-in-WASM database tests passed **104** RAG and **65** public-example checks. No model answer, hosted database or deployed website is inferred from these tests. Final protocol, distribution and source-binding receipts are retained under `docs/evidence/timeline-search/` and the artifact directory.
