### Routes and interaction contract

`pages/calendar-atlas.html` plus five real pages: `pages/calendars/western.html`, `vedic.html`, `egyptian.html`, `hebrew.html` and `chinese.html`. All share `assets/js/app/calendar-atlas.js` and `assets/css/calendar-atlas.css`. Hebrew's route maps to catalogue family `jewish`. The main route also supports `family=islamic` and `family=civil`, keeping the full seven-family catalogue accessible.

The catalogue supplies 32 named variants with available, partial or unavailable status at calculation time. The UI does not synthesize missing variants. All/selected matrix views, single-method inspection, source anchors and exact-result disclosures operate on real canonical output. Solar/lunar tabs display shared measured geometry and explicitly distinguish it from family-specific religious or historical calculations. Local date/time resolution uses the canonical DST gap/fold checks.

Stable controls: `atlas-form`, `atlas-date`, `atlas-time`, `atlas-zone`, `atlas-lat`, `atlas-lon`, `atlas-system`, `atlas-fold`, `atlas-update`, `atlas-error`, `atlas-status`; result controls `atlas-dial`, `atlas-context`, `atlas-variant-list`, `atlas-all`, `atlas-clear`, `atlas-selected-only`, `atlas-view`, `atlas-single`, `atlas-matrix`, `atlas-reading`; exports `atlas-json`, `atlas-svg`, `atlas-share`, `atlas-export-status`; privacy component `atlas-personal`; Hebrew study `atlas-hebrew-text`, `atlas-hebrew-result`.

Public URL fields are `at`, `lat`, `lon`, `zone`, `system`, `prayerMethod`, `asr`, `highLatitude`, optional `variants` and main-route `family`. They are rebuilt from the current validated public context; no personal birth or letter-study input is added. Editing the public moment disables export; a failed calculation retains the visibly stale prior plate. Private context is held separately through the personal component's normalized API, refreshed after public changes and cleared on page hide.

The Hebrew route offers an additional functional letter ledger using the existing standard and mispar-gadol tables. The UI bounds input to 160 characters, reports ignored non-table characters, shows each accepted letter's value and both totals, and links the complete existing Kabbalah tool. It makes no inference from birth data or a calendar date. Input text is excluded from the public atlas export.
