Separate descriptive features

Compare the fixed editorial features.

Each event sample is compared with eight nearby samples at the same observer and clock, ±7, 14, 21 and 28 days. Index differences describe these samples; they do not explain the recorded outcome.

Weighted rule indices run from −100 to 100; the Mercury match uses only 0 or 100. These are index points, not probabilities. Compare values only within the same feature and observer; the shared scale does not make countries or traditions comparable. “Unavailable” means required information is missing, not a score of zero.

Nearby dates are not verified non-event controls. They can lie within the same election or war and can be reused. This sample does not estimate event base rates, prediction accuracy or success beyond chance. Equal values are ties; missing rules stay unavailable.
