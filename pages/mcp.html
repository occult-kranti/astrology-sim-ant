Private remote connection

The backend is published and requires your OAuth sign-in. This connection page is hosted on GitHub Pages; the MCP server runs on the linked private backend because Pages cannot execute server code.

Streamable HTTP · authenticated requests · 11 read-only calculation tools

Open private backend
  1. Open Plugins → Personal → Created by you in ChatGPT and choose Astrologer’s Workbench MCP.
  2. Install or connect the plugin and complete the OAuth sign-in for your private backend.
  3. Ask your client to call workbench_catalogue with {}. This read-only call verifies your connection.

This page does not connect or send personal inputs automatically. A successful server deployment is separate from your client’s connection status.

Local desktop alternative

No hosting account is needed. Install Node 22+, clone the whole repository and run npm ci in its mcp/ directory. Configure your client with the actual path:

{"mcpServers":{"workbench":{"command":"node","args":["/absolute/path/astrology-sim-ant/mcp/stdio.mjs"]}}}

Inputs, methods and privacy

Tools calculate only the arguments you explicitly supply. They do not read this browser’s saved births, notes or API keys. Your chosen client may retain its conversation.

Use ISO instants with Z or an explicit offset and geographic degrees. Unknown birth time cannot support precise houses. Election scans, text and response sizes are bounded. Read workbench://methods in your client for engine conventions, sources and limits.

Astronomical measurements, traditional interpretations and generated symbolic geometry remain distinct. Calibration checks time, location and method choices; it does not infer spiritual effectiveness.
