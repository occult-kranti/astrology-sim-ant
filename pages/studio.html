Set up an MCP client

No MCP endpoint is connected by this page. No reading, birth data or key is sent automatically. A private OAuth-protected backend is available at Workbench MCP. Connect it in your external client; this page stays local.

For a desktop client, clone the repository and run npm ci inside its mcp directory. Configure a local stdio server with your actual absolute path:

node /absolute/path/astrology-sim-ant/mcp/stdio.mjs

A GitHub Pages site cannot run this process. For a separately deployed HTTP server and client configuration, follow the current setup instructions.
