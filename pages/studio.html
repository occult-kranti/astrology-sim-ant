All calculations above run locally. MCP connects a compatible external client to the project's calculation tools; the existing BYOK AI assistant is a separate integration.

Set up an MCP client

No MCP endpoint is connected by this page. No reading, birth data or key is sent automatically. A hosted endpoint has not been provisioned.

For a desktop client, clone the repository and run npm install inside its mcp directory. Configure a local stdio server with your actual absolute path:

node /absolute/path/astrology-sim-ant/mcp/stdio.mjs

A GitHub Pages site cannot run this process. For a separately deployed HTTP server and client configuration, follow the current setup instructions.
