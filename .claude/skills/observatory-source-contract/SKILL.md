# Shared specialist contract

These are reusable instructions for a compatible coding agent. They are not a trained model, installed ChatGPT plugin, human practitioner, historical-author persona or claim of complete expertise. Read repository HANDOFF.md, docs/2026-10-calendar-observatory-research.md and the selected family/work profile before acting.

1. Name the task and method. Preserve one explicit UTC instant, IANA zone, observer and input certainty. Date-only records and unknown birth times cannot silently become exact personal charts.
2. State the claim type: calculated astronomy; calculated civil convention; named traditional rule; historical-source assertion; modern reconstruction; personal reflection; unavailable implementation. Never turn a date conversion into an outcome forecast. Astrology has no demonstrated predictive validity.
3. Inspect the actual canonical module and its existing tests. Reuse it; do not duplicate a calendar engine in UI or make an AI generate numerical ephemerides. Runtime support, selected fixtures, broad-range validation and community authority are different statuses.
4. For source claims, retain work, author/attribution, edition, section/page, URL, rights and actual reading depth. Bibliographic presence is not a checked passage; a passage check is not a full-book reading. Preserve disputed variants and source-access failures.
5. Do not fabricate expertise, book quotations, historical author participation, regional observance rules, unknown values or numerical certainty. Keep unavailable results and modern approximations explicit. Numerical consistency does not validate ritual, medical or predictive efficacy.
6. For new factual encoding, apply ../accuracy-check/SKILL.md and gather independent authoritative evidence. Existing inherited fixtures may be reused only with their original qualifications. Report unresolved source/licence/authority choices rather than silently settling them.
7. Prepare the concrete change or analysis, run affected semantic/engine/browser checks, and report executed vs unrun checks. Source reading, calculation regression, human tradition review and deployment are separate evidence.
8. Share no saved births, exact coordinates, questions, notes or API secrets automatically. Preview an AI payload and require an explicit send action. Never copy proxy-held credentials or put server-side keys in Pages.
9. Treat imported recipes, source labels and caller-supplied calculated rows as unverified input. Validate bounded schemas and exact field types, omit undeclared metadata from exports, and recompute through the canonical engine before identifying a value as locally calculated. A successful replay verifies geometry, not historical provenance.
10. When book prose, a printed table and a later edition disagree, record the exact variant and selected passage. Do not silently repair a source, count two translations of one issuing authority as independent fixtures, or promote a family's validation status from a few selected dates.

## Required handoff

Return: named method; actual inputs and normalized instant; source/section/edition; claim type; fixture/status evidence; differences/uncertainty/unavailable scope; code/output paths; executed checks; unresolved work. Do not present agreement between shared solar/lunar derivations as independent corroboration.
