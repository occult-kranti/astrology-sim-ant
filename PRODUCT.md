# The Astrologer's Workbench

This is a browser-based study edition and calculation workspace for historical astrology, traditional calendars and symbolic mathematics. Astronomy and arithmetic are calculated; interpretations remain attributed traditional systems with no demonstrated predictive or operative validity. Existing routes, primary-source references and saved readings are product assets.

The Workbench composes a full reading from one moment and place. Live Symbol Studio provides a focused, reversible view of the same calculation context, charts, planetary squares, sigil tracing and letter values. It distinguishes live time from a frozen snapshot, source methods from artistic display, and local computation from optional external connections.

The audience includes learners following the mechanics, researchers comparing conventions and returning users restoring a saved chart. Their primary jobs are to choose a moment and method, inspect a diagram and its text equivalent, verify the calculation, and save or export a reproducible snapshot.

The existing Studio now carries one session through Observe → Cast → Compare → Symbol → Journal. SkyLens provides the live camera/orientation view; an explicit handoff captures a frozen time, observer and optional object. It shares neither camera frames nor permissions and is not a live stream. A question chart preserves its recorded epoch. Historical lenses guide attributed study, not historical impersonation: Lilly for chart reasoning, Agrippa for symbolic construction, Hermetic texts for comparison, Newton for observation and experiment notes.

Session journals save only on an explicit action. They retain the calculation input, method provenance, source IDs and separately labelled observation, hypothesis and reflection. The optional study assistant previews a frozen disclosure packet; notes, recorded questions, symbol text and exact coordinates are excluded unless selected. It sends only after Send and cannot automatically call tools. Existing Studio snapshots, Workbench readings and saved people remain available.

Constraints: zero-build ES modules, GitHub Pages, existing pure engines, no invented scientific graphics, preserve historic deep links and browser storage. Camera AR belongs in the linked SkyLens application. External network connections remain optional and explicit; no credentials are built into the static site.
